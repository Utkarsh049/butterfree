# Data Directory

This folder holds datasets for tasks, telemetry, and machine learning models.

## Structure
- `sample_tasks.json`: Initial ground-truth and planned task records (Task Type, Weather, Skill, Machine Age, Duration).
- `sample_telemetry.json`: Telemetry logs with engine hours, fuel, load cycles, idling, seatbelt status, and proximity.
- `raw/`: Unmodified incoming telemetry logs and external data dumps.
- `processed/`: Cleaned, normalized, and feature-engineered datasets used for model training and analysis.
