# Frontend Operator Dashboard

Vite + React single-page application tailored for CAT machinery operators.

## Features
- **Daily Task Dashboard**: View planned vs actual times, schedule tasks, and trigger ML duration estimation.
- **Safety & Proximity Radar**: Live seatbelt compliance badge and proximity hazard alerts.
- **Training Hub**: Operator courses and simulation module browser.
- **Machine Telemetry & Anomaly Feed**: Operational logs with idling threshold and anomaly indicators.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.
